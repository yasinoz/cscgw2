# CLCOR-OP 2.0 — Türkçe Lab Çalışma Kılavuzları

Bu depo, **CLCOR-OP 2.0** (Implementing and Operating Cisco Collaboration
Core Technologies — On-Premises) laboratuvarları için **Türkçe çalışma
kılavuzlarını** (companion) içerir.

Kılavuzlar, lab sırasında kullandığınız **resmi (İngilizce) Lab Guide'ın
yanında** okunmak üzere hazırlanmıştır. Her adım Türkçe anlatılır; menü ve
düğme adları, komutlar, dosya adları ve IP'ler ekranda göründüğü gibi
birebir bırakılmıştır. Amaç, resmi kılavuzun yerini almak değil,
anlaşılmasını kolaylaştırmaktır.

## İçindekiler

| # | Lab | Dosya |
|---|---|---|
| 0 | Uzak Lab Ortamına Erişim | [00-uzak-lab-erisimi.tr.md](00-uzak-lab-erisimi.tr.md) |
| 1 | CUCM'de CA-İmzalı Sertifikaların Uygulanması | [01-ca-imzali-sertifikalar.tr.md](01-ca-imzali-sertifikalar.tr.md) |
| 2 | Destekleyici IP Ağ Protokolleri (DHCP / DNS / NTP) | [02-ip-ag-protokolleri.tr.md](02-ip-ag-protokolleri.tr.md) |
| 3 | Elle IP Telefon Yönetimi (şablonlar, BAT, firmware) | [03-elle-ip-telefon-yonetimi.tr.md](03-elle-ip-telefon-yonetimi.tr.md) |

*(Yeni lab kılavuzları eklendikçe liste güncellenecektir.)*

## Nasıl kullanılır

1. Resmi Lab Guide'daki ilgili Discovery'yi açın.
2. Buradaki aynı numaralı Türkçe kılavuzu yanında açın.
3. Adımları takip edin; "neden" açıklamaları ve sık karşılaşılan sorunlar
   tablosu her kılavuzun içindedir.

Bu materyal sınıf-içi eğitim kullanımı içindir. Kılavuzlardaki içerik
özgündür; komut, değer ve arayüz adları ilgili lab pod'una aittir.
